# 可直接交给定时 AI 的任务

使用 `marketing-buddy-weekly-update` Skill，对 `morningzy123-cloud/first-website` 执行一次 Marketing Buddy 周度更新。

严格读取仓库中的 `automation/weekly-update.config.json`，只研究四个固定市场过去 30 天内的新变化，同时检查现有促销是否过期。政策与海关检查不得跳过。保留仍有效的基线数据，不要重写整个数据库。

只有属于自动发布清单、来源充分、数据验证和网站测试全部通过的纯数据变更，才可以提交到生产分支并等待 Vercel 自动部署。涉及竞品增删、车型级关税适用、来源冲突、Schema、网页代码、设计、部署配置或定时设置的变化，必须放入审核分支并停止自动合并。

若没有变化，提交无变化报告，不创建空提交。若任何检查失败，保持线上版本不变并说明原因。完成后返回本周变化、过期项目、保留审核项目、测试结果、提交 SHA、部署状态和网站地址。
