# 每周定时任务指令

使用 `marketing-buddy-weekly-update` Skill（不支持Skill安装时读取已保存的同名 SKILL.md 及 references），为 Marketing Buddy 执行一次四国 C级 Sedan 每周更新。

仓库：morningzy123-cloud/first-website；分支 main；正式站：https://first-website-five-chi.vercel.app/ 。

本任务授权你按规范研究、直接核验、更新公开数据、创建并合并通过检查的数据PR，触发既有 Vercel 自动部署，并确认正式站内容。无需每周再询问相同的发布许可。范围仅为既有四国和竞品池；保留 Marketing Buddy、金毛、蓝色 UI与阿联酋四款 AI建议状态。

从最新 main 和当前数据开始。默认查询最近7天，漏跑时补查自上次成功更新以来的窗口；首页最多4条仍有时效的高价值事件。重点查当地经销商报价/优惠/金融与保修、官网卖点、官方PDF配置及中文、消费者实评、可靠销量/排名、重大政策、墨西哥/沙特/阿联酋发运周期。按规范留28项覆盖记录。

搜索摘要不能充当原文，销量无可靠口径就不展示，政策区分提案/生效状态和车型适用条件，物流区分参考与估算。来源冲突、访问失败、未知新官方域名列待核实，保留旧可信记录，其他可靠数据继续处理。不为了周更刷新日期或生成新闻。

先生成 submission.json 和私有研究报告，再运行 prepare 与发布计划检查。只允许更改 public.json、public.bundle.js、release.json。通过对应提交的CI和Vercel预览后才合并；合并后核对正式站三份文件。失败或状态未知就停止并报告，不修改检查规则、不强推、不盲目回滚。

无实质变化时不提交、不部署。结束返回一屏中文：更新成功/无变化/未完成；最重要的变化、待核实项、正式链接、PR与验证结果、私有报告位置。定时运行只在完成、失败或需要我处理时通知，不连续发送无意义进度。
